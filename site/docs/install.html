Install

wheelripe is a small pure-Python package (one dependency: packaging). It runs on Python 3.9+ — the interpreter you run it with does not need to be the one you are targeting.

Run once with uvx

uvx --from git+https://github.com/Blackman99/wheelripe wheelripe
# pin a release
uvx --from git+https://github.com/Blackman99/wheelripe@v0.1.0 wheelripe uv.lock -p 3.15t

Install with pipx

pipx install git+https://github.com/Blackman99/wheelripe
wheelripe --version

From the release wheel

Every GitHub Release carries the wheel and sdist built in CI:

pip install https://github.com/Blackman99/wheelripe/releases/download/v0.1.0/wheelripe-0.1.0-py3-none-any.whl

wheelripe is not on PyPI yet; until it is, install from GitHub as above. The commands stay the same once it is.

In CI

Nothing to install — use the GitHub Action. It creates its own virtualenv, so it never touches the Python your job uses.

Network

wheelripe makes one HTTPS request per package to the PyPI JSON API (https://pypi.org/pypi/<name>/json), eight in parallel by default. With --index-url / --extra-index-url it asks those simple-API indexes instead (one request per package per index), and PyPI is not contacted unless you list it. Behind a proxy, the usual HTTPS_PROXY variable is honoured; for a private CA, set SSL_CERT_FILE. See Indexes.
