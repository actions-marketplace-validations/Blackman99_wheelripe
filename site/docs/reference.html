Flags

wheelripe [PATH|SPEC ...] [options]
wheelripe wheel FILE.whl ... [-p PY] [--platform KEY]
wheelripe mcp
FlagDefaultMeaning
-p, --python3.15Target CPython; t = free-threaded.
--platform KEYlinux-x86_64, macos-arm64, windows-amd64Repeat or comma-separate.
--all-platformsEvery known key.
--glibc / --musl / --macos2.34 / 1.2 / 14Oldest system you deploy on.
-f, --formattexttext, json, markdown, github.

Exit codes

CodeMeaning
0Nothing at or above the --fail-on level.
1Something is; the report says what.
2Usage error, unreadable input, an index that could not be reached, or one that answered with something that is not a simple index page.

Statuses

StatusMeaning
readyA wheel for this version installs on the target.
skipAn environment marker excludes the package on this target.
buildThe release has only an sdist (for every Python).
bumpNo wheel at this version; fix names the first newer release with one.
blockedNo release has a wheel for the target yet.
excludedThe release's requires-python excludes the target.
missingThe package or version is not on the index.

A package's overall status is its worst status across the platforms you asked for.

Yanked files (PEP 592) are skipped, as pip skips them — except when an exact pin selects a yanked release: pip installs it then, with a warning, so wheelripe judges that release and marks the package "yanked": true.

    {
      "name": "numpy", "version": "1.26.4", "pinned": true,
      "status": "bump", "fix": "2.5.2",
      "platforms": {"linux-x86_64": {"status": "bump", "note": "..."}},
      "latest": "2.5.4", "ships": ["cp39", "cp310", "cp311", "cp312"],
      "requires_python": ">=3.9",
      "upstream": "https://github.com/numpy/numpy",
      "origin": "uv.lock"
    }
  ]
}

Packages are sorted worst first. Fields that do not apply are omitted. Two top-level fields appear only when they have something to say: indexes (the indexes consulted, redacted, when anything besides PyPI was used, e.g. ["download.pytorch.org/whl/cpu", "pypi.org"]) and warnings (index problems such as a 401, also printed to stderr).
